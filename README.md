# chess-vision

Скриншот шахматной доски с Windows-ПК по горячей клавише → MacBook находит доску, распознаёт
фигуры, строит FEN, считает Stockfish и показывает в браузере лучший ход стрелкой.

```
Windows (client)  ──F8──▶  POST /analyze (PNG)  ──▶  Mac (server): доска → фигуры → FEN → Stockfish → страница анализа
```

**Ничего настраивать не нужно.** Клиент сам находит мак в локальной сети и сопрягается с ним,
шаблоны фигур строятся автоматически из эталонного скриншота chess.com.

## Быстрый старт

### 1. Mac (сервер) — запустить первым

```bash
git clone https://github.com/AkaiRep/chess-vision.git
cd chess-vision
./start_server.command
```

Или скачайте ZIP с GitHub, распакуйте и дважды кликните `start_server.command`
(если macOS ругается на «неизвестного разработчика» — правый клик → «Открыть»).

Скрипт сам поставит всё нужное: Homebrew (спросит разрешения), Python 3.12, **Stockfish** и
Python-пакеты в `.venv`. При первом старте macOS спросит **«Разрешить входящие подключения?»** —
нажмите **«Разрешить»**. Затем откроется страница анализа `http://localhost:8765`.

### 2. Windows (клиент)

Скачайте/склонируйте репозиторий и дважды кликните **`start_client.bat`**.
Если Python нет, скрипт поставит его через `winget` и попросит запустить себя ещё раз.

| Действие | Как |
|---|---|
| Скриншот → анализ на маке | `F8` |
| Выбрать область с доской мышкой (запоминается) | `Ctrl+F8` |
| Забыть область, снимать весь монитор | `start_client.bat --reset-region` |
| Одна отправка без хоткея | `start_client.bat --once` |

В консоли клиента печатается лучший ход и FEN. Звук «дзинь» — проанализировано,
«ошибка» — доска не найдена, позиция некорректна или сервер недоступен.

## Страница анализа

- Доска в вашей ориентации: **ваша сторона всегда снизу**.
- Зелёная стрелка — лучший ход, бледные синие — 2-й и 3-й варианты (MultiPV = 3).
- Оценка текстом (с точки зрения белых, `#3` — мат в 3) и полоской слева от доски.
- Три варианта с главной линией, FEN с кнопкой «Копировать».
- Превью скриншота с красной рамкой найденной доски.
- Подсветка последнего хода; **красным** — клетки, в распознавании которых программа не уверена.
- Кнопки:
  - **Перевернуть доску** — если ориентация определилась неверно;
  - **Сменить сторону хода** — по умолчанию считается, что ход ваш;
  - **Перекалибровать** — построить шаблоны фигур заново по последнему скриншоту (см. ниже).

Ручные «перевернуть» и «сменить сторону» действуют на текущий скриншот; следующий F8 снова
определяет всё автоматически. Страницу можно открыть и с другого компьютера в сети:
`http://<IP мака>:8765`.

## Как это работает

1. **Поиск доски.** На скриншоте ищется самая большая квадратная область из двух цветов клеток
   (кремовые и зелёные), проверяется чередование 8×8; интерфейс сайта вокруг отсекается.
   Место доски запоминается — пока она там же, повторный поиск не нужен.
2. **Фигуры.** Каждая клетка сравнивается с шаблонами 12 фигур (template matching) только по
   центральным ~70 % — координаты в углах не мешают. Фон клетки (светлая, тёмная, подсвеченная)
   вычитается, поэтому цвет клетки не влияет на распознавание.
3. **Ориентация.** По цифрам рядов в левом столбце («8» сверху — вы белыми, «1» сверху — чёрными).
   Если цифр нет — по положению белого короля и фигур.
4. **Сторона хода** — ваша. Если на скриншоте подсвечен последний ход и сходила ваша фигура,
   страница предупредит. **Рокировка** разрешена, если король и ладья на исходных полях;
   **взятие на проходе** — по подсвеченному ходу пешки на два поля.
5. **Проверка.** Невозможная позиция (два короля, пешка на 1-й горизонтали, шах не той стороне…)
   показывается с объяснением, движок не запускается.
6. **Stockfish** запущен постоянно, 1 секунда на позицию, 3 лучших варианта.

## Калибровка

При первом запуске шаблоны строятся сами из `samples/full_screen_start.png` (chess.com, тема
«зелёная», фигуры «Neo») и сохраняются в `data/templates/templates.npz`.

Если у вас другие фигуры или распознавание ошибается:

1. Откройте на сайте доску с **начальной позицией** (ваши фигуры снизу — белые или чёрные).
2. Нажмите **F8**.
3. На странице анализа нажмите **«Перекалибровать»**.

Программа проверит, что это действительно начальная позиция, вырежет шаблоны всех фигур и
заново измерит цвета клеток. Из терминала то же самое: `python -m server.calibration image.png`.

> Поиск доски рассчитан на двухцветные плоские доски; цвета клеток берутся из калибровки, но
> первый поиск ищет цвета, близкие к зелёной теме chess.com.

## Если не находит сервер

1. Сервер запущен? В его окне должна быть строка `listening on http://192.168.x.y:8765`.
2. **Firewall мака** (Системные настройки → Сеть → Брандмауэр): разрешите входящие подключения для
   Python, либо временно отключите брандмауэр для проверки.
3. **Локальная сеть** (macOS 15+: Конфиденциальность и безопасность → Локальная сеть): разрешите
   доступ Терминалу, из которого запущен сервер.
4. Оба компьютера в одной сети? Гостевой Wi-Fi и «изоляция клиентов» в роутере блокируют связь.
5. Клиент пишет `pairing window closed` — перезапустите сервер на маке и нажмите F8 в течение
   10 минут (новые устройства сопрягаются только сразу после старта сервера).

**Поиск сервера:** сначала mDNS (Bonjour), если не сработал — перебор своей подсети `/24` по
порту 8765. **Сопряжение:** сервер при первом запуске генерирует секрет (`server_state.json`),
клиент получает его через `POST /pair` — только из локальной сети и только 10 минут после старта.

**IP мака** печатается при старте сервера; ещё: Системные настройки → Wi-Fi → «Подробнее…»,
или `ipconfig getifaddr en0` в терминале.

## Необязательный конфиг

Всё работает без него. Чтобы поменять хоткей, монитор, порт, время анализа и т.п., скопируйте
`config.example.toml` в `config.toml` и раскомментируйте нужное.

## Обновление

```bash
git pull            # затем снова ./start_server.command (на маке) / start_client.bat (на Windows)
```

## Отладка

- Логи: `logs/client.log`, `logs/server.log`.
- Принятые скриншоты сохраняются на маке в `server/inbox/` (последние 50).
- Распознать картинку без клиента:

  ```bash
  .venv/bin/python -m server.debug_recognize server/inbox/<файл>.png   # Windows: .venv\Scripts\python
  ```

  Печатает FEN и предупреждения, кладёт в `debug_out/` `<имя>_overlay.png` (скриншот с рамкой
  доски) и `<имя>_board.png` (доска с распознанной фигурой и score в каждой клетке; красная
  рамка — неуверенно, жёлтая — подсвеченная клетка).

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Тесты движка запускаются, если найден Stockfish (на маке — после `brew install stockfish`;
на Windows — путь в переменной `STOCKFISH_PATH`).

Помимо реальных скриншотов из `samples/`, тесты строят синтетические скриншоты chess.com из
настоящих спрайтов фигур (`tests/synth.py`) с заранее известным FEN: середина партии, игра за
чёрных, подсветка последнего хода, взятие на проходе, эндшпиль, превращённые фигуры,
маленькая доска в JPEG, доска без координат.

## Структура

```
client/   Windows: хоткей, захват (mss), выбор области, поиск сервера, отправка
server/   macOS:
  app.py            FastAPI: /analyze, /pair, страница, кнопки, WebSocket
  board_locator.py  поиск доски по цветам клеток
  recognizer.py     распознавание фигур (template matching), цифры рядов
  calibration.py    шаблоны из начальной позиции
  position.py       ориентация, сторона хода, рокировки, en passant, валидация → FEN
  engine.py         постоянный Stockfish, MultiPV
  pipeline.py       скриншот → анализ, ручные переключатели
  render.py         SVG доски со стрелками, превью
  static/           страница анализа
shared/   конфиг, протокол, сетевые утилиты
tests/    pytest + генератор синтетических скриншотов
samples/  эталонные скриншоты
```
