# chess-vision

Скриншот шахматной доски с Windows-ПК по горячей клавише → MacBook распознаёт позицию,
строит FEN, считает Stockfish и показывает лучший ход.

```
Windows (client)  ──F8──▶  POST /analyze (PNG)  ──▶  Mac (server): доска → FEN → Stockfish → UI
```

**Ничего настраивать не нужно.** Клиент сам находит мак в локальной сети и сам с ним сопрягается.

> Статус: готов этап 1 (сеть). Поиск доски, распознавание, движок и интерфейс — следующие этапы.

## Быстрый старт

### 1. Mac (сервер) — запустить первым

```bash
git clone https://github.com/AkaiRep/chess-vision.git
cd chess-vision
./start_server.command
```

Или скачайте ZIP с GitHub, распакуйте и дважды кликните `start_server.command`
(при первом запуске macOS может ругаться на «неизвестного разработчика» — правый клик → «Открыть»).

Скрипт сам поставит всё нужное: Homebrew (спросит разрешения), Python 3.12, Stockfish и
Python-пакеты в `.venv`. При первом старте macOS спросит **«Разрешить входящие подключения?»** —
нажмите **«Разрешить»**.

### 2. Windows (клиент)

Скачайте/склонируйте репозиторий и дважды кликните **`start_client.bat`**.
Если Python нет, скрипт поставит его через `winget` и попросит запустить себя ещё раз.

Клиент найдёт мак и сопряжётся с ним. Дальше:

| Действие | Как |
|---|---|
| Скриншот и отправка | `F8` |
| Выбрать область с доской мышкой (запоминается) | `Ctrl+F8` |
| Забыть область, снимать весь монитор | `start_client.bat --reset-region` |
| Одна отправка без хоткея (проверка) | `start_client.bat --once` |

Звук: «дзинь» — отправлено, «ошибка» — смотрите консоль или `logs/client.log`.

## Как это работает

**Поиск сервера.** Сервер объявляет себя через mDNS (Bonjour). Если mDNS в сети не проходит,
клиент сканирует свою подсеть `/24` на порту 8765 и узнаёт сервер по ответу `GET /health`.
Найденный адрес запоминается в `client_state.json`; если мак сменил IP, поиск повторится сам.

**Сопряжение.** При первом запуске сервер генерирует секрет (`server_state.json`). Клиент получает
его через `POST /pair` — это разрешено **только из локальной сети и только 10 минут после
запуска сервера**. Потом скриншоты принимаются только от уже сопряжённых устройств.
Если клиент сообщает `pairing window closed` — перезапустите сервер на маке и нажмите F8.

## Если не находит сервер

1. Сервер запущен? В его окне должна быть строка `listening on http://192.168.x.y:8765`.
2. **Firewall мака** (Системные настройки → Сеть → Брандмауэр): разрешите входящие подключения для
   Python, либо временно отключите брандмауэр для проверки.
3. **Локальная сеть** (macOS 15+: Конфиденциальность и безопасность → Локальная сеть): разрешите
   доступ Терминалу, из которого запущен сервер.
4. Оба компьютера в одной сети? Гостевой Wi-Fi и «изоляция клиентов» в роутере блокируют связь.
5. В крайнем случае задайте адрес вручную — см. ниже.

### IP-адрес мака

Он печатается при старте сервера. Ещё способы: Системные настройки → Wi-Fi → «Подробнее…» → IP-адрес,
или в терминале `ipconfig getifaddr en0`.

## Необязательный конфиг

Всё работает без него. Чтобы поменять хоткей, монитор, порт и т.п., скопируйте
`config.example.toml` в `config.toml` и раскомментируйте нужное. Там же можно жёстко задать
`server_url` и общий `token` вместо автопоиска и сопряжения.

## Ручная установка (без скриптов)

```bash
# Mac
brew install python@3.12 stockfish
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements-server.txt
python -m server
```

```powershell
# Windows
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements-client.txt
python -m client
```

## Логи и отладка

- `logs/client.log`, `logs/server.log`
- Все принятые скриншоты сохраняются на маке в `server/inbox/` (последние 50).

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest
```

## Структура

```
client/   Windows: хоткей, захват (mss), выбор области, поиск сервера, отправка
server/   macOS: FastAPI, сопряжение, mDNS, приём скриншотов
shared/   конфиг, протокол, сетевые утилиты
tests/    pytest
samples/  эталонные скриншоты
```
